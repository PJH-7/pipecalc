PipeCalc는 유량·압력·온도·배관 치수를 입력하여 유속, 압력강하, 출구압력과 기체 Mach 수를 계산합니다. 신규 배관의 후보 Size 비교와 기존 배관의 증량 가능성 검토에 사용할 수 있습니다.

어디에 사용하는가빠른 사용 순서입력값 이해하기계산 작동 원리결과 해석하기물성 계산과 직접입력상변화·임계조건실무 사용 시 주의사항

1. 어디에 사용하는가

적합한 사용별도 전문 검토가 필요한 사용
신규 배관 Size 후보 비교기액 2상 압력강하 계산
기존 배관의 유량 증가 가능성 확인Flash, 응축, 비등이 실제로 발생하는 라인
설계 계산서의 유속·압력강하 개략 검산분기·병렬 배관망, 다수 사용처가 연결된 Network
회의·현장에서 빠른 배관 적합성 확인펌프·압축기 성능, Control Valve, Relief·Flare Sizing
배관 Size 변경에 따른 영향 비교수격, 진동, 소음, 배관응력, 재질·부식 적합성
PipeCalc 결과는 FIELD/FEED 단계의 1차 판단용입니다. PASS가 상세설계 승인이나 안전성 보증을 의미하지는 않습니다.

2. 빠른 사용 순서

1
기체 또는 액체 선택유체의 실제 운전 상태를 선택합니다. 같은 물질도 기체와 액체는 계산 방법이 다릅니다.
2
유체 선택NG, Steam, N₂, Water, EDC, VCM, NaOH 등 목록에서 선택합니다. 지원되지 않는 액체는 밀도와 점도를 직접 입력할 수 있습니다.
3
유량·압력·온도 입력압력은 barg입니다. 기체의 Nm³/h와 실제 m³/h는 의미가 다르므로 반드시 구분합니다.
4
NPS·Schedule·재질 선택앱은 배관 외경과 벽두께로 내경을 계산합니다. 재질은 관내 거칠기인 절대조도 ε에 반영됩니다.
5
길이·고도차·부속 여유 입력상향 배관은 고도차를 +로 입력합니다. 엘보·밸브 등의 손실은 부속 여유율로 간단히 반영합니다.
6
판정 기준 확인 후 계산일반 배관, 펌프 전단, 냉각수, 공용 헤더 또는 사용자 정의 기준을 선택합니다.
7
하단 결과를 눌러 상세값 확인Reynolds 수, 마찰계수, 밀도, 점도, Z, 내경, 출구압력과 경고 사유를 확인합니다.

배관 치수 적용 범위

앱의 치수 데이터는 ASME B36.10-2022 기준입니다. 재질을 스테인리스로 선택해도 치수는 B36.10을 사용하고 조도만 바뀝니다. ASME B36.19M의 Schedule 5S·10S·40S·80S가 필요한 경우에는 실제 배관 내경을 별도로 확인해야 합니다.

4. 계산 작동 원리

4.1 배관 내경과 유속

배관 외경(OD)에서 벽두께 두 배를 빼서 내경(ID)을 구하고, 내경으로 유로 단면적을 계산합니다.

ID = OD − 2 × Wall Thickness
A = πD² / 4
V = Q / A

같은 유량에서 내경이 작아지면 유속이 증가합니다. 압력강하는 유속의 제곱에 크게 영향을 받으므로, 배관 Size가 한 단계만 달라져도 결과 차이가 크게 날 수 있습니다.

4.2 Reynolds 수와 마찰계수

Re = ρVD / μ

Reynolds 수(Re)는 유동이 점성의 영향을 많이 받는지, 관성의 영향을 많이 받는지를 나타냅니다. 앱은 Re와 상대조도 ε/D를 이용해 Darcy 마찰계수 f를 계산합니다.

Reynolds 수유동 특성앱 처리
Re < 2,300층류(Laminar)f = 64/Re
약 2,300~4,000천이영역(Transition)계산은 수행하지만 결과 신뢰도를 낮게 표시
Re가 충분히 큼난류(Turbulent)Colebrook–White 식으로 f 반복계산

주의: Re가 10⁵ 이상이라고 항상 완전조도 난류(Fully Rough)인 것은 아닙니다. 완전조도 상태는 Re뿐 아니라 상대조도 ε/D에도 좌우됩니다.

4.3 액체 압력강하

ΔPfriction = f(L/D)(ρV²/2)
ΔPstatic = ρgΔz
ΔPtotal = ΔPfriction + ΔPstatic

액체는 밀도 변화가 작다고 보고 Darcy–Weisbach 식을 사용합니다. 상향 배관에서는 정수두가 추가되고, 하향 배관에서는 정수두가 압력 회복 방향으로 작용합니다.

4.4 기체 압력강하

P₁² − P₂² = f(L/D)G²ZRsT

기체는 압력이 떨어지면 밀도가 감소하고 유속이 증가합니다. 따라서 액체처럼 일정 밀도로 계산하지 않고, 배관을 40개 구간으로 나누어 각 구간의 압력·Z·밀도·점도를 다시 계산합니다.

기체 계산은 등온(Isothermal) 가정입니다. 큰 감압으로 실제 온도 변화가 중요한 경우에는 HYSYS, Aspen, AFT Arrow 등으로 재검토해야 합니다.

5. 결과 해석하기

판정의미권장 조치
PASS현재 설정된 유속·압력강하·Mach·최소 출구압 기준을 모두 만족상세 계산값과 예상 계산 범위를 함께 확인
FAIL하나 이상의 설정 기준을 초과배관 Size 확대, 유량 조정, 길이·부속·최소 요구압 재검토
CAUTION계산은 완료됐지만 물성 신뢰도나 적용범위 때문에 추가 확인 필요실제 물성값 입력 또는 전용 프로그램으로 검증
HOLDFlash·응축 가능성, 상태 선택 불일치 또는 기체 임계조건 도달단상 계산값 채택 금지. 상평형 또는 압축성 상세해석 수행

주요 출력값

출력값의미
Velocity액체는 평균 유속, 기체는 배관을 따라 계산된 최대 유속입니다.
ΔP / 100m마찰에 의한 압력강하를 100m 기준으로 환산한 값입니다. 고도차에 의한 정수두는 제외됩니다.
Outlet Pressure마찰손실과 고도차를 반영한 예상 출구 게이지압입니다.
Mach Number기체 유속을 음속으로 나눈 값입니다. 소음·진동·압축성 영향 판단에 사용합니다.
Reynolds Number층류·천이·난류 상태를 판단하는 무차원 수입니다.
Friction Factor배관 마찰손실을 결정하는 Darcy 마찰계수입니다.
예상 계산오차통계적으로 보증된 확률 범위가 아닙니다. 물성자료의 신뢰도, Z 모델 간 차이, 적용 온도범위, 상변화 접근 여부 등을 반영해 넓게 잡은 1차 검토용 참고 범위입니다.
예: 계산 ΔP가 0.50 bar이고 예상 계산오차가 ±20%라면, 앱은 0.40~0.60 bar를 참고 범위로 보여줍니다. 실제값이 이 범위에 들어올 확률이 95%라는 의미는 아닙니다.

입력값이나 배관 조건을 변경하면 이전 결과는 자동으로 삭제됩니다. 변경된 조건에서는 반드시 다시 계산하십시오.

판정 기준 프로파일

일반 배관, 펌프 전단, 냉각수, 공용 헤더, 사용자 정의 기준을 저장할 수 있습니다. 기본값은 법규나 국제표준이 아니라 예시값이므로, 실제 사용 전 사내 Design Criteria에 맞게 수정해야 합니다.

6. 물성 계산과 직접입력

압력강하는 밀도 ρ, 점도 μ, 기체 압축계수 Z에 영향을 받습니다. 앱은 유체와 운전조건에 따라 물성을 자동 추정하지만, 공정 Simulator·공급사 Data Sheet·분석값이 있다면 직접 입력값을 우선 사용하는 것이 좋습니다.

유체앱의 물성 처리사용 시 주의사항
NG·LNG BOGDAK 또는 Peng–Robinson으로 Z 계산, Lee–Gonzalez–Eakin으로 점도 추정조성이 없으므로 Dew Point와 Bubble Point는 계산하지 못합니다.
N₂·Air·H₂·CO₂·에틸렌·프로필렌Pitzer 또는 Peng–Robinson 자동 선택임계점 근처에서는 물성이 급변할 수 있습니다.
SteamPeng–Robinson EOS로 Z와 밀도를 추정Steam 전용 표준인 IAPWS-IF97은 구현되어 있지 않습니다. 일반적인 과열증기 1차 검토에는 사용할 수 있지만, 포화선 근처·임계영역·고정확도 계산은 IF97 또는 전용 도구로 확인하십시오.
Water·Cooling Water0~100℃ 물 밀도 근사식과 Vogel 점도식염류, Glycol, 부식억제제 등 실제 냉각수 조성은 반영하지 않습니다.
메탄올·에탄올NIST 자료를 바탕으로 한 저압 액체 점도식고압에서 점도의 압력 의존성은 반영하지 않습니다.
액체 EDC·VCM·Cl₂기준 밀도·점도와 온도보정식운전조건의 실제 물성값이 있으면 직접 입력을 권장합니다.
NaOH 수용액농도와 온도 표를 2차원 보간20~100℃, 0~50 wt% 밖에서는 가장 가까운 경계값을 사용하고 신뢰도를 낮게 표시합니다.
기타 액체·액체 암모니아밀도와 점도 직접입력두 값이 모두 입력되기 전에는 계산하지 않습니다.

기체 밀도 또는 Z를 직접 입력할 때

기체 밀도와 Z는 서로 독립적인 값이 아닙니다.

ρ = P / (ZRsT)
Z = P / (ρRsT)
  • 밀도 ρ를 직접 입력하면 앱은 그 밀도에 맞는 유효 Z를 역산하여 압력강하 계산에 사용합니다.
  • Z를 직접 입력하면 앱은 그 Z에 맞춰 입구 밀도를 다시 계산합니다.
  • 비현실적인 Z가 계산되면 단위·소수점·barg/bara 입력 오류 가능성이 높으므로 계산을 중단하거나 CAUTION으로 표시합니다.
기체 밀도를 직접 입력할 때는 반드시 운전 압력·온도 조건의 밀도인지 확인하십시오. 정상상태 밀도나 다른 압력 조건의 밀도를 입력하면 잘못된 Z가 계산됩니다.

7. 상변화 경고와 기체 임계조건

Flash·응축 가능성

앱은 실제 2상 압력강하를 계산하지 않습니다. 사용 가능한 유체는 포화압력 Psat과 입·출구 절대압력을 비교하여 단상 계산을 계속 사용해도 되는지 확인합니다.

조건판정의미
액체 압력이 Psat 근처 이하HOLD배관 중 Flash 가능성이 있으므로 단상 액체 계산값 채택 금지
기체 압력이 Psat보다 높거나 매우 근접HOLD 또는 CAUTION기체 선택이 잘못됐거나 응축 가능성 확인 필요
NG·LNG BOG판정 제한조성이 없어 혼합물 Dew/Bubble Point를 계산하지 못함
NaOH 수용액판정 제외농도별 기액평형 자료 미지원

기체 임계조건

기체가 배관을 따라 팽창하면서 속도가 계속 증가하면 단순 등온 P² 식을 더 이상 안전하게 적용하기 어려운 구간에 도달할 수 있습니다. 앱은 내부 중단 기준에 도달하면 계산을 억지로 계속하지 않고 HOLD로 표시합니다.

등온 모델 중단 기준: Maiso = 1 / √k

이 판정은 실제 Fanno Flow 또는 Real-Gas Choked Flow를 완전하게 계산한 결과가 아닙니다. 배관 Size 확대 또는 전용 압축성 유동 해석이 필요하다는 경고입니다.

8. 실무 사용 시 주의사항

계산 전 확인

  • 유체 상태가 실제로 단상인지 확인합니다.
  • 압력 단위가 barg인지 확인합니다.
  • Nm³/h와 운전 m³/h를 구분합니다.
  • NPS와 Schedule을 도면·Line List와 대조합니다.
  • 노후 배관, Scale, 부식이 예상되면 조도를 보수적으로 선택합니다.
  • 엘보·티·밸브가 많으면 부속 여유율을 높이거나 별도 K값 계산을 수행합니다.

결과 확인

  • PASS만 보지 말고 유속, ΔP/100m, 출구압력, Mach를 각각 확인합니다.
  • CAUTION이면 실제 밀도·점도·Z를 확보하여 다시 계산합니다.
  • HOLD이면 단상 계산 결과를 설계값으로 사용하지 않습니다.
  • 펌프 전단은 PipeCalc 결과와 별도로 NPSHa/NPSHr를 검토합니다.
  • 공용 Header는 동시사용률과 분기별 최소 공급압을 별도로 확인합니다.

현재 지원하지 않는 항목

  • 실제 Two-Phase Pressure Drop
  • 배관망·분기·병렬 Network 해석
