4. 계산 작동 원리

4.1 배관 내경과 유속

배관 외경(OD)에서 벽두께 두 배를 빼서 내경(ID)을 구하고, 내경으로 유로 단면적을 계산합니다.

ID = OD − 2 × Wall Thickness
A = πD² / 4
V = Q / A

같은 유량에서 내경이 작아지면 유속이 증가합니다. 압력강하는 유속의 제곱에 크게 영향을 받으므로, 배관 Size가 한 단계만 달라져도 결과 차이가 크게 날 수 있습니다.

4.2 Reynolds 수와 마찰계수

Re = ρVD / μ

Reynolds 수(Re)는 유동이 점성의 영향을 많이 받는지, 관성의 영향을 많이 받는지를 나타냅니다. 앱은 Re와 상대조도 ε/D를 이용해 Darcy 마찰계수 f를 계산합니다.

Reynolds 수유동 특성앱 처리
Re < 2,300층류(Laminar)f = 64/Re
약 2,300~4,000천이영역(Transition)계산은 수행하지만 결과 신뢰도를 낮게 표시
Re가 충분히 큼난류(Turbulent)Colebrook–White 식으로 f 반복계산

주의: Re가 10⁵ 이상이라고 항상 완전조도 난류(Fully Rough)인 것은 아닙니다. 완전조도 상태는 Re뿐 아니라 상대조도 ε/D에도 좌우됩니다.

4.3 액체 압력강하

ΔPfriction = f(L/D)(ρV²/2)
ΔPstatic = ρgΔz
ΔPtotal = ΔPfriction + ΔPstatic

액체는 밀도 변화가 작다고 보고 Darcy–Weisbach 식을 사용합니다. 상향 배관에서는 정수두가 추가되고, 하향 배관에서는 정수두가 압력 회복 방향으로 작용합니다.

4.4 일반 기체 압력강하

P₁² − P₂² = f(L/D)G²ZRsT

NG, N₂, Air, H₂, CO₂, EDC·VCM·Cl₂ 증기 등은 압력이 떨어질 때 Z, 밀도, 점도를 다시 계산하며 기존 등온 P² 적분을 사용합니다. Steam은 이 식을 사용하지 않습니다.

4.5 Water·Steam 전용 계산

Water, Steam, Cooling Water는 IAPWS-IF97로 각 구간의 밀도, 엔탈피, 열용량, 음속, 등온압축률을 구하고 IAPWS 2008 식으로 점도를 계산합니다. 배관은 최소 40구간으로 나누며 압력 또는 밀도 변화가 큰 구간은 자동으로 더 잘게 나눕니다.

dP/dx = −[ fG²/(2ρD) + ρg(dz/dx) ] / [ 1 − G²κT/ρ ]
항뜻실무 해석
fG²/(2ρD)마찰 압력구배배관이 작고 질량유속이 클수록 커집니다.
ρg(dz/dx)고도에 의한 압력구배상향은 압력손실, 하향은 압력회복 방향입니다.
κT등온압축률(Isothermal Compressibility)압력 변화에 따라 밀도가 얼마나 변하는지를 나타냅니다.
1−G²κT/ρ압축성 가속 보정0에 접근하면 등온 단상 정상해를 계속 계산할 수 없어 HOLD입니다.
단상 기체와 Water·Steam 계산은 등온(Isothermal) 가정입니다. 2상 모드는 별도로 등엔탈피(Isenthalpic) HEM을 적용합니다. 실제 열손실, 응축·비등 속도, 유동양식이 중요한 경우에는 전용 다상유동 도구로 재검토해야 합니다.

4.6 순수 Water/Steam 2상 참고 계산

2상 모드는 순수 H₂O가 포화액과 포화증기로 평형을 이룬다고 가정합니다. 입구 압력과 품질 x를 입력하거나, 입구 압력과 비엔탈피 h를 입력하여 품질을 계산합니다.

x = (h − hf) / (hg − hf)
vm = (1−x)/ρf + x/ρg
ρm = 1/vm
α = (x/ρg) / vm
전문용어상세 설명예시
HEM
Homogeneous Equilibrium Model		액체와 증기가 같은 속도로 흐르고 압력·온도 평형을 즉시 이룬다고 보는 모델입니다. 상간 Slip과 실제 유동양식은 무시합니다.x=20%여도 낮은 증기밀도 때문에 Void Fraction α는 매우 클 수 있습니다.
Slip증기와 액체의 실제 평균속도가 서로 다른 현상입니다. HEM은 Slip ratio=1로 가정합니다.층상류·환상류에서는 증기가 액체보다 빠르게 움직일 수 있습니다.
Lockhart–Martinelli/Chisholm액상 단독·기상 단독의 마찰구배를 계산한 뒤 2상 마찰승수를 적용하는 분리유동 상관식입니다.앱은 HEM 마찰손실과 비교해 민감도를 표시합니다.
Void Fraction α배관 단면 또는 체적에서 증기가 차지하는 비율입니다. 질량분율 x와 다릅니다.x=10%가 α=10%라는 뜻은 아닙니다.

HEM 가속항은 등엔탈피 상태에서 혼합비체적의 압력 미분으로 계산합니다.

dP/dL = −[ fG²/(2ρmD) + ρmg(dz/dL) ] / [ 1 + G²(∂vm/∂P)h ]

Lockhart–Martinelli/Chisholm은 마찰항만 비교합니다. 두 마찰손실의 상대차가 30%를 넘으면 PipeCalc가 결과를 채택하지 않고 HOLD합니다.

2상 기능의 ±30~50%는 통계적 신뢰구간이 아니라 제품 내부의 보수적 참고 Band입니다. REFERENCE도 상세설계 승인값이 아닙니다.

4.7 제한적 Gas-Liquid 참고 계산

v7.2 Gas-Liquid 모드는 사용자가 입구조건의 양상 물성을 알고 있고, 배관 중 상변화·반응·용해가 없다고 보는 등온 2성분 흐름만 다룹니다. 기상 질량분율은 배관 전체에서 고정하며, 기상밀도만 고정 Z 등온 근사로 압력에 비례하여 갱신합니다.

ρG(P) = ρG,1(P/P₁)
vm = (1−xg)/ρL + xg/ρG(P)
α = (xg/ρG) / vm

마찰손실의 주 계산은 분리유동 상관식인 Lockhart–Martinelli/Chisholm을 사용합니다. HEM은 No-slip 민감도 비교값으로만 사용합니다.

X² = (dP/dL)L / (dP/dL)G
φL² = 1 + C/X + 1/X²
(dP/dL)LM = φL²(dP/dL)L
전문용어상세 설명예시
Superficial Velocity
표면유속 jL, jG		각 상이 배관 전체 단면을 단독으로 흐른다고 가정해 계산한 속도입니다. 두 값의 합이 HEM No-slip 혼합유속입니다.jG가 2 m/s라고 해서 실제 기상 평균속도가 정확히 2 m/s라는 뜻은 아닙니다.
Liquid Hold-up특정 배관 구간에서 액체가 실제로 차지하는 체적분율입니다. 경사와 유동양식에 따라 No-slip Void Fraction과 달라집니다.층상류에서는 액체가 하부에 쌓여 실제 Hold-up이 HEM 예측과 다를 수 있습니다.
Fixed-Z Isothermal온도와 기체 압축계수 Z가 일정하다고 보고 기상밀도를 압력에 비례시킵니다.총 ΔP가 입구 절대압력의 10%를 넘으면 이 근사의 영향이 커져 HOLD합니다.
Gas-Liquid 모드는 VLE, Dew/Bubble, Flash, 실제 Flow Regime, Slugging 및 Hold-up을 계산하지 않습니다. 입력한 ρ·μ가 틀리면 결과도 그대로 틀리므로, Simulator 또는 실측 물성과 대조해야 합니다.

ΔP / 100m마찰에 의한 압력강하를 100m 기준으로 환산한 값입니다. 고도차에 의한 정수두는 제외됩니다.
Outlet Pressure마찰손실과 고도차를 반영한 예상 출구 게이지압입니다.
Mach Number기체 유속을 음속으로 나눈 값입니다. 소음·진동·압축성 영향 판단에 사용합니다.
Reynolds Number층류·천이·난류 상태를 판단하는 무차원 수입니다.
Friction Factor배관 마찰손실을 결정하는 Darcy 마찰계수입니다.
jL / jGGas-Liquid 각 상의 표면유속입니다. 실제 상별 속도나 실제 Hold-up과 동일하지 않습니다.
예상 계산오차통계적으로 보증된 확률 범위가 아닙니다. 물성자료의 신뢰도, Z 모델 간 차이, 적용 온도범위, 상변화 접근 여부 등을 반영해 넓게 잡은 1차 검토용 참고 범위입니다.
예: 계산 ΔP가 0.50 bar이고 예상 계산오차가 ±20%라면, 앱은 0.40~0.60 bar를 참고 범위로 보여줍니다. 실제값이 이 범위에 들어올 확률이 95%라는 의미는 아닙니다.

입력값이나 배관 조건을 변경하면 이전 결과는 자동으로 삭제됩니다. 변경된 조건에서는 반드시 다시 계산하십시오.

판정 기준 프로파일

일반 배관, 펌프 전단, 냉각수, 공용 헤더, 사용자 정의 기준을 저장할 수 있습니다. 기본값은 법규나 국제표준이 아니라 예시값이므로, 실제 사용 전 사내 Design Criteria에 맞게 수정해야 합니다.

기체 밀도 또는 Z를 직접 입력할 때

기체 밀도와 Z는 서로 독립적인 값이 아닙니다.

ρ = P / (ZRsT)
Z = P / (ρRsT)
  • 밀도 ρ를 직접 입력하면 앱은 그 밀도에 맞는 유효 Z를 역산하여 압력강하 계산에 사용합니다.
  • Z를 직접 입력하면 앱은 그 Z에 맞춰 입구 밀도를 다시 계산합니다.
  • 비현실적인 Z가 계산되면 단위·소수점·barg/bara 입력 오류 가능성이 높으므로 계산을 중단하거나 CAUTION으로 표시합니다.
기체 밀도를 직접 입력할 때는 반드시 운전 압력·온도 조건의 밀도인지 확인하십시오. 정상상태 밀도나 다른 압력 조건의 밀도를 입력하면 잘못된 Z가 계산됩니다.

8. 실무 사용 시 주의사항

계산 전 확인

  • 유체 상태가 실제로 단상인지 확인합니다.
  • 압력 단위가 barg인지 확인합니다.
  • Nm³/h와 운전 m³/h를 구분합니다.
  • NPS와 Schedule을 도면·Line List와 대조합니다.
  • 노후 배관, Scale, 부식이 예상되면 조도를 보수적으로 선택합니다.
  • 엘보·티·밸브가 많으면 부속 여유율을 높이거나 별도 K값 계산을 수행합니다.

결과 확인

  • PASS만 보지 말고 유속, ΔP/100m, 출구압력, Mach를 각각 확인합니다.
  • CAUTION이면 실제 밀도·점도·Z를 확보하여 다시 계산합니다.
  • REFERENCE이면 HEM 결과를 참고값으로만 사용하고 유동양식·Slip·열손실을 포함한 상세검증을 수행합니다.
  • Gas-Liquid REFERENCE이면 입력 물성의 출처와 운전조건을 확인하고, 실제 Hold-up·Flow Regime을 포함하는 전용도구로 교차검증합니다.
  • HOLD이면 단상·2상 전체 결과를 설계값으로 사용하지 않습니다.
  • 펌프 전단은 PipeCalc 결과와 별도로 NPSHa/NPSHr를 검토합니다.
  • 공용 Header는 동시사용률과 분기별 최소 공급압을 별도로 확인합니다.

현재 지원하지 않는 항목

  • 다성분 기액평형, Dew/Bubble, Flash 및 비평형 상변화
  • 유동양식·Slip·실제 Hold-up을 포함한 상세 Two-Phase Pressure Drop
  • Slugging, Terrain Slugging, 열손실·응축·비등 속도
  • 배관망·분기·병렬 Network 해석
  • Control Valve Cv 및 펌프·압축기 성능곡선
  • Relief·Flare Sizing
  • Water Hammer, 배관응력, 진동·소음, Erosion, 재질 적합성
  • ASME B36.19M Schedule S 치수
